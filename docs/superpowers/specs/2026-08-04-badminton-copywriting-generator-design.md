## 1. 产品定位

为抖音博主「进进睡不着🏸」（抖音号 36303724，湖北，羽毛球+手势舞/甜舞赛道）打造的**手机端文案生成工具**。

核心约束：**文案库不收录该博主本人的文案**。工具是给她用的，必须保证她拿到的每条文案都新鲜、不与自己的历史内容重复。素材全部来自同赛道其他博主的爆款文案。

## 2. 目标用户与使用场景

- 用户：羽毛球女博主，发作品前快速找文案
- 场景：拍完"穿羽毛球服跳手势舞/甜美舞蹈"的视频后，在手机上打开工具 → 选分类或随机 → 一键复制 → 粘贴到抖音发布页

## 3. 功能清单

| 功能 | 说明 |
|---|---|
| 🎲 一键随机 | 首页大按钮，点一下出一条文案，再点换一条（避免连续重复） |
| 🏷️ 分类筛选 | 5 个 tab：甜美撒娇 / 自信反差 / 羽毛球梗 / 歌词向 / 互动召唤 |
| 📋 一键复制 | 点复制按钮，文案+推荐标签一起进剪贴板，toast 提示成功 |
| 🔖 收藏 | 心形按钮收藏，localStorage 持久化，独立"收藏"tab 查看 |
| #️⃣ 标签推荐 | 每条文案附带 2-4 个推荐话题标签，随文案一起复制 |

非目标（YAGNI）：账号系统、后端服务、UGC 投稿、按 BGM 搜索、AI 生成（本期不做，仅预留）。

## 4. 文案库设计（核心）

### 4.1 采集来源
- 抖音同赛道博主作品文案：话题 #打羽毛球女生 #羽毛球手势舞 #羽毛球变装 下的热门视频
- 采集方式：无头浏览器（Playwright + Edge）抓取抖音网页版
- **硬性过滤：排除「进进睡不着」本人（sec_uid: MS4wLjABAAAAh-UpfxoPLhq6E6Iy1K_wHUAnZn927vZ9m2dBZ_1esjU）的全部内容**

### 4.2 筛选标准（风格画像，基于对目标博主的分析）
1. 口语短句，以 ≤40 字为主
2. 甜美/俏皮/撒娇语气
3. 与羽毛球场景相关（球、球服、球馆、球搭子、球瘾等元素）
4. 反差/自信感文案可用
5. 与舞蹈 BGM 绑定的热梗（xx摇、手势舞）可用

### 4.3 数据结构
```json
[
  {
    "id": "001",
    "text": "文案正文",
    "category": "sweet | confident | badminton | lyric | interact",
    "tags": ["#羽毛球", "#打羽毛球女生", "#手势舞"]
  }
]
```

分类定义：
- sweet（甜美撒娇）：撒娇、可爱、甜妹语气
- confident（自信反差）：自信、反差、俏皮回怼
- badminton（羽毛球梗）：球瘾、球馆、球搭子等场景梗
- lyric（歌词向）：歌词片段、氛围感短句
- interact（互动召唤）：召唤球搭子、@好友、提问互动

### 4.4 规模
目标 150-200 条，每个分类 30-40 条。采集不足时由人工（AI 整理）按风格标准补充同风格文案，并在文档中标注补充部分。

## 5. 技术方案

- **单个 index.html**：内嵌 CSS + 原生 JS + 文案 JSON，零依赖、零构建
- 收藏数据存 localStorage
- 移动端优先，375px 基准适配
- 部署：GitHub Pages（免费静态托管），产出公开链接供博主手机访问，可"添加到主屏幕"

## 6. 视觉风格

- 甜系运动风：清新薄荷绿 + 樱花粉主色调，🏸 元素点缀
- 大圆角卡片、柔和阴影、大按钮
- 文案卡片居中突出，操作按钮位于底部拇指热区
- 顶部：分类 tab（含收藏 tab）；中部：文案卡片；底部：随机大按钮

## 7. 未来扩展预留（方案 C 升级路径）
